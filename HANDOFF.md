## Gotchas
- Editing files from the shell: bash heredocs with quotes or backticks break. Write a small Python script with the Write tool into the scratchpad and run it. When editing CRLF files keep line endings.
- In the browser pane the viewport is narrow by default (<1100px stacks the layout and hides the drag handles); use resize_window 1500x850 to test, then reset to desktop.
- Windows: set PYTHONIOENCODING=utf-8. Bash heredocs with quotes break: write files with the file tool. Python edits to CRLF files: preserve line endings.
- Next.js 16 differs from older versions: read app/node_modules/next/dist/docs before writing Next code. A "LayoutProps not found" tsc error is normal when .next types are missing.
- Do NOT rm -rf app/.next while the dev server runs. Port 3000 may be taken by my CRM project.
- UI tests with clicking must use a COPY of the database (DATABASE_URL env var), never the real crest_forensic.db. To click through the signed-in app, start the API on a copy, set throwaway passwords on the copy only (auth.hash_password), and delete the copy afterwards.
- Don't download files without asking; tcs.com blocks bots, I put PDFs in Documents myself.
- /users page: never put the .sym class (inline-flex) on a <td>; it breaks the row lines. Wrap the text in a span.
